# FindMySpot Landingpage

Landingpage für den FindMySpot-Prototyp im Rahmen der Vertiefungsarbeit 2026 an der GBS St. Gallen.

## Entwicklung

```bash
pnpm install
pnpm dev
```

## Prüfung

```bash
pnpm lint
pnpm build
```

## Inhalte

Externe Links und Kontaktdaten werden zentral in `src/data/site.ts` verwaltet.
