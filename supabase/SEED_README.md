## How the mappings work

- `places.category_id → categories.id`: the seed resolves each category by its slug.
- `place_features.place_id → places.id`; `place_features.feature_id → features.id`: each place has all nine feature mappings, with feature IDs resolved by slug.
- Boolean features store `true` or `false` in `boolean_value`, with `rating_value = NULL`.
- Quietness stores its 1–5 score in `rating_value`, with `boolean_value = NULL`.
- `place_purposes.place_id → places.id`; `place_purposes.purpose_id → purposes.id`: purpose IDs are resolved by slug. An unlisted purpose has no mapping in this seed.
- Coordinates are passed to `ST_MakePoint(longitude, latitude)`, assigned SRID `4326`, then cast to `geography`.
- All places are inserted with status `approved`. Only Stadtpark and Mülenenschlucht have a `NULL` address.
- Inserts use `ON CONFLICT DO NOTHING`: conflicting existing rows are skipped, not updated. Resolved category and feature IDs come from the matching database rows.
